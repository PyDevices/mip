mip

mip — a MicroPython package index.

Install current packages as precompiled MicroPython bytecode or portable Python source.

GitHub Repo

Installing packages from this index

Index URL: https://PyDevices.github.io/mip

MicroPython REPL or script

import mip

mip.install(
    "package-name",
    index="https://PyDevices.github.io/mip",
)

Hosted MicroPython command line

micropython -m mip install \
  --index https://PyDevices.github.io/mip \
  package-name

# Add --target lib for an explicit workspace destination.
# Add --no-mpy when portable .py source is required.

mpremote and a connected device

mpremote connect /dev/ttyUSB0 mip install \
  --index https://PyDevices.github.io/mip \
  package-name

Index behavior

The public index follows the current source release.

MicroPython targets receive architecture-neutral .mpy files by default. Source installs receive .py files. Named dependencies resolve from the same index.

Only latest.json package manifests are public. Historical version aliases are intentionally not retained.
