This index no longer takes releases

New PyDevices releases are published at lib.omnipython.org. Install from there with omip:

import omip
omip.install("palettes")

omip comes with OmniPython firmware. On other MicroPython firmware, run mip.install("github:PyDevices/pydevices/lib/omip.py") once to put it on the board.

The packages published here before it stopped stay up, so a board that already points at this address keeps working, but they will not get newer versions. Move to lib.omnipython.org to get them.
