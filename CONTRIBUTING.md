# Contributing

This repository is the **generated MIP package index** for PyDevices — see
the note at the top of the README. There is nothing to contribute here
directly:

- **Package bugs** belong to the package's own repository
  (github.com/PyDevices/<repo>/issues — the README's package list links
  each one).
- **Index problems** (a wrong or missing version, a failed publication):
  open an issue on this repository.
- **Publishing changes** happen in the component repos and
  `PyDevices/.github`'s shared workflows, never by editing package trees
  here.

The upstream `micropython-lib` trees carried verbatim in this fork follow
upstream's own contribution process at
https://github.com/micropython/micropython-lib.
