# PyDevices package index

A `mip` package index at `https://PyDevices.github.io/mip`. It carries every PyDevices library and all of micropython-lib, each as precompiled `.mpy` files or plain `.py` source.

## Get started

- [Install a package](get-started/install.md): from a board, from your computer, or from the unix port.

## Guides
