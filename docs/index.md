# PyDevices package index (retired)

This index no longer takes releases. Install PyDevices packages from
[lib.omnipython.org](https://lib.omnipython.org) with `omip`; the
[README](../README.md) shows how.

What it published before it stopped stays up, and these pages describe it:

- [Packages in this index](reference/packages.md): every PyDevices package, its version and where it came from.
- [How the index was built](how-it-works/index.md): the lockfile, the publication queue, and why only the latest version is listed.
